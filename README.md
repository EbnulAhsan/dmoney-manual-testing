### Manual Software Testing Assignment

## 📋 Overview

This repository documents an end-to-end manual testing exercise: analyzing
system requirements, deriving test scenarios, executing functional and
negative test cases, and reporting defects with supporting evidence — the
core workflow of a QA engineer's day-to-day work.

---

## 📁 Assignment Contents

| # | Section | Description |
|---|---------|-------------|
| 1 | dMoney Commission & Limit Rules | Business rules for commission calculation and transaction limits |
| 2 | dMoney Bug Report | Documented defects (BUG-001–BUG-004) with reproduction steps |
| 3 | dMoney Self Cash-in Test Cases | Test cases for self cash-in via Stripe |
| 4 | EasyPay Acceptance Criteria | Derived acceptance criteria from requirements |
| 5 | EasyPay Test Cases | Functional test case suite for EasyPay |
| 6 | Manual Testing Theoretical Questions | Core QA concept Q&A |
| 7 | Bug Evidence Screenshots | Visual proof supporting each reported defect |
